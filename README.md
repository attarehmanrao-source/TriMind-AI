# TriMind AI 🤖

**Three Challenges. Three Predictions. One AI Platform.**

A unified Streamlit intelligence platform with three ML/DL rooms:

| Room | Task | Models |
|------|------|--------|
| 📈 Sales Analytics | Profit prediction (regression) | Linear Regression · Random Forest · Neural Network (MLP) |
| 👥 Customer Churn | Churn prediction (classification) | Logistic Regression · Random Forest · Neural Network (MLP) |
| 🧑‍💼 HR Analytics | Attrition prediction (classification) | Logistic Regression · Random Forest · Neural Network (MLP) |

## ✨ Highlights

- 🎬 Cinematic AI intro video on launch
- 🌌 Dark navy/purple AI theme + animated robot (Lottie)
- 🔊 Voice announcements at every pipeline stage
- 📊 Interactive Plotly charts, KPI cards, live training progress
- 🔮 Prediction forms + downloadable HTML reports per room
- 🎓 Campus card in the sidebar
