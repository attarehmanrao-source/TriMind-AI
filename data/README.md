# Data folder

Sample datasets live here. They are **not committed to git** (see `.gitignore`).

Download them with:

```bash
curl -L -o data/sales_sample.csv https://raw.githubusercontent.com/krishnaa-tech/sample-superstore/master/SampleSuperstore.csv
curl -L -o data/churn_sample.csv https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv
curl -L -o data/hr_sample.csv https://raw.githubusercontent.com/IBM/employee-attrition-aif360/master/data/emp_attrition.csv
